en: **Everyone sees the same offline players** — The server now moves offline players (sitting, walking, sleeping in beds) and shares it, so every player with Living Horizon sees them at the same place doing the same thing. An offline player also gets out of bed when a real player sleeps in it. Turn it off with *shareRestingLife*.

Un joueur déconnecté se lève aussi quand un vrai joueur dort dans son lit. Désactivable avec *shareRestingLife*.
